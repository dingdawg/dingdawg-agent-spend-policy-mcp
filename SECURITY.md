# Security policy

## Supported versions

Only the latest published version is supported.

## Reporting a vulnerability

Please use GitHub's private vulnerability-reporting feature for this repository.
Do not include credentials, payment data, or private customer information in a
public issue. We aim to acknowledge valid reports within 14 days and will post
coordinated remediation information when a fix is available.

This package is a local policy evaluator. A report involving payment execution,
customer keys, settlement, or custody may concern an integrating system rather
than this package, but we still welcome the report so it can be routed safely.
